# Skärmbilder

Lägg skärmbilden av den lyckade tvåfaktorsinloggningen här, till exempel som
`inloggning-2fa.png`, och länka den från `REPORT.md`.

Flödet att fånga: logga in med e-post och lösenord, skriv den sexsiffriga koden
ur autentiseringsappen på `/Account/LoginWith2fa` och fånga sidan du landar på
som inloggad.
